# AGUADO AI

La inteligencia artificial de **AGUADO STUDIO** para crear juegos de Roblox.

Página: https://punticoyt-boop.github.io/aguado-ai/

La IA corre gratis en tu PC con [Ollama](https://ollama.com). Para usarla desde esta página:

1. Instala Ollama y descarga el modelo: `ollama pull qwen2.5-coder:7b`
2. En PowerShell: `setx OLLAMA_ORIGINS "https://punticoyt-boop.github.io"`
3. Cierra Ollama y vuelve a abrirlo, y recarga la página.
